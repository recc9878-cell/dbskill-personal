# dbs-viewpoint：观点衍生（内测）

**性质**：dontbesilent 内测 skill，2026-08-04 由用户并入 dbs 家族。更新源外的内测版，`/dbs-update` 不会覆盖它。
**创建日期**：2026-03-07（原版）

## 核心功能

输入一段文字，AI 识别领域并推荐相关大咖，用户确认后生成多角度观点库。

**核心价值**：
- 为内容创作提供多角度理论支撑
- 避免单一视角的局限性
- 快速建立理论背书和权威感
- 发现更犀利的表达角度

## 执行流程（分两步）

### 第一步：领域识别 + 大咖推荐

1. **分析用户输入的文字**：提取核心主题、识别涉及领域、判断适合的理论框架。

2. **输出领域识别结果**：
   ```markdown
   ## 📋 领域识别结果

   **主领域**：[领域名称]
   **相关领域**：[领域 1]、[领域 2]

   **主题分析**：[一句话说明这段文字在讨论什么问题]
   ```

3. **推荐大咖列表**（10-15 位）：按领域分类展示，用 ✅ 标记 4-5 位核心推荐（最相关的），每位注明核心理论框架。

4. **提供 5 个选项**：直接生成（✅ 核心推荐）／生成全部／我来指定／调整领域／追加大咖。

5. **等待用户确认**——第一步必须停在这里，不要直接生成。

### 第二步：生成观点库

根据用户确认的大咖列表，生成完整 markdown 文件，包含：元信息（原始文字、领域、生成时间）、快速索引（核心洞察汇总、可引用金句）、大咖观点详解（按领域分类）、使用建议（适合的内容形式、可能的争议点、深化方向、组合建议）。

**保存位置**：默认 `01-内容生产/内容素材库/观点库/YYYY-MM-DD_[主题]_观点库.md`。**若该路径不存在**（这台机器上可能没有这个目录结构），先问用户存哪里；用户不指定就存到当前工作目录，并告知路径。

## 每位大咖的输出原则

1. **真实性原则**：基于大咖的真实理论框架，不胡编乱造；不确定的观点不强行生成；明确标注「基于 XX 理论框架」。
2. **差异性原则**：每位大咖的视角要有明显区别，避免「换个名字说同样的话」。
3. **可用性原则**：观点要能直接用于内容创作，提供可引用的金句和可操作的洞察。
4. **深度原则**：不是简单的「XX 说过」，而是用理论框架分析具体问题。

每位大咖的输出结构：视角（一句话）→ 观点（200-300 字，模拟其思维方式）→ 核心洞察（1-3 条）→ 可引用表达（一句可直接入稿的话）。

## 进阶功能

- **指定大咖**：`/观点衍生 [文字] --大咖=阿德勒,齐泽克,塔勒布`
- **指定领域**：`/观点衍生 [文字] --领域=心理学,哲学`
- **深化某位大咖**：用户说「深化阿德勒的观点」→ 展开该理论框架 500-800 字
- **观点对比矩阵**：自动生成维度 × 大咖的对比表（问题根源／解决方案／适用场景）

---

## 注意事项

1. 第一步必须等待用户确认，不要直接跳到第二步。
2. 核心推荐（✅）要精准：4-5 位必须是最相关的。
3. 大咖库可扩展：用户提到不在列表中的大咖，可以临时添加。
4. 保持理论真实性，不为凑数胡编。
5. 输出结构化，便于检索和复用。
