**性质**：dontbesilent 内测 skill，2026-08-04 由用户并入 dbs 家族。更新源外的内测版，`/dbs-update` 不会覆盖它。

当用户提供短视频文案并请求批量生成开头时，使用以下框架。

## 与 dbs-hook 的分工（重要）

| | dbs-hook | dbs-hook-pro（本 skill） |
|---|---|---|
| 定位 | **诊断先行**：先查内容质量，不达标直接停止优化 | **生成导向**：三方法并行，直接产出大量方案 |
| 独有能力 | 内容完整性检查、素材丰富度检查、话题范围检查 | **个人开头类型库套用**（A/B/C 已验证爆款模式） |
| 什么时候用 | 「我的开头有什么问题」「开头不行怎么办」 | 「给我 10 个开头」「用我的类型库套一批」 |

两者共享同一套开头哲学（开头 = 话题 + Hook + 可信度），诊断类需求走 dbs-hook，批量产出走这里。

## 使用前提

**在使用本 Skill 之前，先确认开头类型库的位置。**

1. 优先查找 `01-内容生产/短视频数据库/分析/开头类型库.md`（A 类反常识／B 类成绩单／C 类体系化输出，附真实爆款例子）。
2. **找不到该文件时不要编造类型库内容**——直接告知用户「未找到开头类型库」，问用户要不要提供路径或贴出内容；用户没有就跳过方法二（模板套用），只用方法一和方法三生成，并说明少了一批。
3. 已经了解用户风格标记（晒结果、括号强调、具体场景、反常识等）时直接使用；第一次服务该用户时先从类型库或其历史文案中提取风格标记。

## 核心概念

### 开头的定义

**开头是内容的试用装，不是标题的延续。**

- 开头必须独立工作（不能假设用户看了标题）
- 开头必须包含完整信息（话题 + Hook + 可信度）
- 开头必须在 5 秒内独立建立吸引力

### 开头公式

```
开头 = 话题 + Hook + 可信度
```

**例子**：
- 话题：选题和标题的区别
- Hook：我去年涨粉 200 万
- 可信度：靠的就是搞清楚这个
- 完整开头：我去年涨粉 200 万，靠的就是搞清楚选题和标题的区别

### 常见错误

1. **假设用户看了标题**：「（你上班上多了）」缺话题建立 → 改为「一个人赚不到钱的核心原因就是（你上班上多了）」
2. **只重复标题没有新信息**：「今天我们来讲选题和标题的区别」没 Hook → 加成绩/数据
3. **开头太抽象**：「今天这个话题很重要…」没说是啥话题 → 直接说话题
4. **直接给答案没悬念**：「李亚鹏 30 年干黄十几个项目，证明人脉不等于赚钱」说了答案 → 「善良的李亚鹏，认识半个娱乐圈，30 年为什么赚不到钱」
5. **自问自答、书面语**：「你以为你在自律？其实你只是在逃避执行」念不出口 → 「只要你没在执行，你的动作大概率就是为了逃避执行而生的动作」

### 为什么开头要重复标题信息

不是浪费，是必要——用户可能没看标题、看了没记住、只被封面吸引，或算法直接推视频。开头必须包含完整话题信息。

## 三种方法（同时执行，合并输出）

**方法一：素材提取**——从文案里提取现有素材，走五步流程生成开头。

**方法二：模板套用**——判断这条视频属于 A/B/C 哪类 → 去开头类型库找同类爆款例子 → 基于例子改写出 3-5 条，标注参考了哪条。（类型库缺失时跳过，见「使用前提」。）

**方法三：素材增补**——假设文案里没有好素材，主动问自己能加什么：相关真实数据或结果（如「我连线了 300 个人发现…」）、具体案例或对比、反常识结论制造冲突。基于增补素材再生成 3-5 条。

---

## 五步流程（方法一的主线）

1. **素材提取**：有没有冲击力数据（大数字／对比数字／百分比）、转变故事（之前 vs 之后）、金句（可独立成立、反直觉）、权威背书（人物／机构／成就）、痛点共鸣（焦虑／错误做法／困境）。
2. **人群分析**：不是这个领域的人会看吗？有没有缩窄人群的词？优化方向：用更普世的切入点（赚钱、改变、成长），先抓注意力再引入专业内容。
3. **标题-内容匹配**：把开头的核心承诺写出来，检查正文能否兑现；不匹配就改开头或改正文。
4. **5 秒 Hook 分析**（优先级排序）：

| 类型 | 优先级 | 原理 | 示例 |
|-----|--------|------|------|
| **晒结果 + 反转** | ⭐⭐⭐⭐⭐ | 可信度 + 好奇 | 去年我发了 1 万多条推文，同时运营 7 个平台——很多人问我执行力怎么这么强，其实我只是搞清楚了一件事：[核心观点] |
| 数据冲击 | ⭐⭐⭐⭐ | 大数字震撼 | 80 亿、400 栋、13000 条 |
| 反差/转变 | ⭐⭐⭐⭐ | 好奇心驱动 | 从攒首付到管理 80 亿 |
| 金句 | ⭐⭐⭐⭐ | 认知冲击 | 不能持有 10 年，就不要持有 10 分钟 |
| 权威+观点 | ⭐⭐⭐ | 借势可信度 | 犹太富豪教我一句话 |
| 痛点+悬念 | ⭐⭐⭐ | 共鸣+好奇 | 研究 3 个月，焦虑 3 年，后悔 30 年 |
| 反直觉 | ⭐⭐⭐ | 挑战认知 | 99% 的人第一步就错了 |
| 提问式悬念 | ⭐⭐⭐ | 好奇心驱动 | 为什么…？怎么会…？ |

「晒结果」优先级最高的原因：用数据证明资格（可信度）＋「很多人问我怎么做到的」制造好奇＋把人群从「想学方法论的人」扩大到「想拿到结果的人」。

5. **生成方案**：三方法各自产出一批，合并输出。

## 评估标准

| 标准 | 问自己 |
|-----|--------|
| 5 秒抓住注意力 | 前 5 秒有没有 Hook？ |
| 人群覆盖广 | 不是这个领域的人会看吗？ |
| 和内容匹配 | 开头承诺的，正文能兑现吗？ |
| 有记忆点 | 看完能记住什么？ |
| 制造好奇 | 会想继续看下去吗？ |
| 保留悬念 | 开头有没有直接给答案？ |
| **口播友好** | 能直接念出来吗？是具体行为还是抽象概念？是直接陈述还是自问自答？ |

## 常见问题诊断

| 问题 | 症状 | 解决方向 |
|-----|------|---------|
| 开头太温和 | 像知乎问题，没有冲击力 | 最有冲击力的素材前置 |
| 开头太窄 | 只有垂直人群会看 | 更普世的切入点包装 |
| 开头和内容不匹配 | 标题问 A，正文讲 B | 统一开头和正文 |
| 开头没有 Hook | 平铺直叙 | 数据、金句、反差、痛点前置 |
| 开头太长 | 5 秒内没进入正题 | 精简到 1-2 句直接给 Hook |
| 开头是书面语 | 自问自答、过于抽象 | 改为直接陈述、具体行为 |
